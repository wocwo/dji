# Bad Cases

## 1. 中文数字导致评测误判

- 用例：`h-air3s-charging`
- 问题：Air 3S 充电管家能给几块电池充电？
- 期望：`三块`
- 回答：`最多可为 3 块智能飞行电池充电`
- 判定：FAIL（claim/number）
- 真实原因：字符串精确匹配，`三块` 与 `3 块` 不等价
- 修复：评测器增加中文数字/单位/空格归一化

**这是评测器坏例，不是模型坏例。** 保留它是为了防止“把 23/24 改成 24/24”式的自我欺骗。

## 2. 视觉：没有真实损伤集

- 当前只测了报错截图、正常产品图、空白图；
- 正常产品图和空白图都没有幻觉出 `visible_damage`；
- 但没有真实坠机/断臂/云台损伤图片，不能证明“损伤识别”有效；
- 视觉模型只做观察，不做维修诊断。

## 3. 视觉延迟

- base64 data URI 直连约 1.4–2.9s；
- 公网 `/v1/attachments/analyze` 仍可能 5–20s；
- 原因是上传、Cloudflare、服务端串行 OCR + 视觉；
- 修复方向：异步视觉、并行 OCR/视觉、缓存。

## 4. 模型可用性

- `qwen-vl` / `qwen-vl-plus` / `qwen-vl-max` 在当前 MaaS 网关 404；
- 只能用 `qwen3-vl-plus`；
- 换模型不是配置改名，必须换网关/账号。

## 5. 图片不持久化

- 图片只在浏览器 Object URL 预览；
- 刷新后历史消息只保留文字，不保留图片；
- 需要对象存储或临时文件服务才能持久化。

## 6. 多用户隔离的边界

- 当前是单进程 + SQLite 命名空间隔离；
- 密码是环境变量明文；
- job 队列在内存，重启丢失；
- 没有审计日志、配额、租户级删除；
- 生产需要 OIDC/哈希密码/HTTPS/审计。

## 7. 数据版权

- 完整 DJI 手册不能直接随仓库开源；
- 公开 Demo 应使用演示语料 `data/agent_demo_corpus.jsonl`；
- 评测集里的页面引用可以作为测试数据，但手册 PDF 本身不要分发。
