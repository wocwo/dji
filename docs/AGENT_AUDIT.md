# Agent 与 DSH 能力差距审计

日期：2026-11-21

| 能力 | 状态 |
|------|------|
| 多轮会话 | 已完成：前端 `session_id` + SQLite turns |
| 滚动摘要 | 已完成：SQLite `session_summaries`，按窗口增量更新 |
| 历史检索 | 已完成：同一 session 内按词面相关度取旧轮次 |
| 新会话 | 已完成：`新问题` 生成新 session |
| 手册引用 | 已完成：页面级 grounding |
| 故障排查 fallback | 已完成：手册无覆盖时给“通用建议（非手册）” |
| 图片视觉 | 已完成：Qwen3-VL 结构化观察 + qwen-vl-ocr 文字；不能替代维修诊断 |
| 自动模式路由 | 已完成：auto 按高风险词选 fast/normal |
| 异步任务 | 已完成：公网隧道下轮询 |
| 进度事件 | 已完成：job `last_event` 驱动“检索/生成/整理”状态 |
| 限流 | 已完成：`AGENT_RATE_LIMIT_PER_MINUTE`，默认 30/分钟 |
| 会话列表 | 已完成：`/v1/sessions` + 侧边栏（公网 Basic Auth 下前端拉取存在兼容问题） |
| 评测 | 已完成：golden + holdout + retrieval-only |

## 仍缺失

| DSH 能力 | Agent 现状 | 影响 |
|----------|------------|------|
| 图片/截图输入 | 仅 OCR 文字 | 不能判断坠机照片的外观损伤 |
| 文件上传 | 不支持 | 不能读日志、发票、维修单 |
| Web 搜索 | 未接入 | 无法查最新固件/公告/价格 |
| 流式 token | 只做异步轮询 | 首字延迟感知差 |
| 多用户隔离 | Basic Auth 单用户 | 不能开放给多人 |
| 工具审批 | 无 | 工具白名单是固定的 |
| 模型路由 | 手动 fast/normal | 还不能按风险自动选 |

## 优先修复顺序

1. **图片输入**  
   故障排查最需要：用户发坠机照片、指示灯状态、App 报错截图。  
   需要视觉模型或 OCR；没有视觉模型时至少支持上传并提示“当前模型不能读图”。

2. **限流 + 会话隔离**  
   公网部署前必须做，否则一个 URL 被转发就会烧 token、串会话。

3. **自动模式路由**  
   高风险问题自动 normal，普通规格/视觉问题 fast。

4. **流式输出**  
   把首字延迟从 5–7 秒降到 1 秒级；隧道下用 SSE 或分块轮询。

5. **Web 搜索**  
   只用于“最新固件/公告/价格”等手册外时效信息，必须与手册引用分开标注。

## 当前结论

长上下文已经不是“没有记忆”，而是：

- 最近 6 轮原文；
- 更早轮次滚动摘要；
- 当前问题相关旧轮次检索；
- 摘要和旧轮次以 `system` 上下文注入。

还不是无限上下文；下一步应控制摘要长度和历史注入 token，并补图片/限流。
